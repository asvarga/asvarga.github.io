Transfinite Zippers

A pure, immutable map from ordinal offsets to values, for interpreters that quote and unquote through towers of machines. move(1) steps to a sibling, move(ω) to a cousin in the next machine, move(ω²) to a second cousin, and every list remembers where you left it.     Each value and the one move that reaches it. Tap one to make that move.

      Move it yourself

      Each move climbs its ordinal's path up the vine, steps along, and comes back down the way that list last went.

      The post's figure

      The post's own drawing, to compare. The page draws the same cells, worked out from the moves, on a dark page.

      The house is the focus. Buckets hold values. Green circles are the vine: a trie of each move's path in bounded parentheses, \ up-left and / up-right, from the house to the lists it can step along. Each row of diamonds is a zipper list, named by the move that walks it; its dark diamond is its chosen child, and its arrows point away from it. A child off the vine keeps its structure in blue circles, one for each \ after the first on its path, each holding the / branch left there (the lists below) and pointing on down to the value it last had in focus. Keys: ← → step, Space next, S sets a value, Home starts over. The URL keeps the steps.
