Projects

Small interactive projects, most of them running right here in your browser.

  • Quilt ↗

    Polyglot metaprogramming language.

    #languages

  • NanoBots ↗

    Compile gas-metered state machines to run on the GPU, right in your browser.

    #languages#gpu#prettyBlog post

  • SatSight

    Solve puzzles like Sudoku, Akari and graph coloring by reduction to SAT, then watch the solver’s discoveries projected back into the puzzle, with the CDCL search steppable one event at a time. Runs in your browser via WebAssembly.

    #proofs#algorithmsGitHub ↗

  • Graphical Proof Assistant

    Graph-based proof assistant using my “Hybrid UI”. I made this tool to help me experiment with type systems.

    #proofs#prettyVideo ↗

  • Verified Ordinal Arithmetic ↗

    Ordinal arithmetic with properties verified in Liquid Haskell (Haskell + refinement types). I proved that my Cantor Normal Form representation of ordinals is closed under the operations needed to implement the Num and Ord typeclasses.

    #proofs#algorithms

  • 3D Fireworks

    Graphics course final project with thousands of particles and real-time lighting.

    #gpu#pretty

  • Hybrid Environments

    A programming language combining static and dynamic scoping. It’s fun but probably a horrible idea; try it in the browser!

    #languages

  • Collision Trees

    Computational art from self-colliding trees with a surprising variety of emergent behaviors.

    #algorithms#pretty

  • Ackermann Blocks

    Interactive Ackermann function visualizer.

    #algorithms
